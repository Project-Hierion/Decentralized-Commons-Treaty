## Principles

- **People Govern** — One person, one voice. No corporate veto.
- **Transparency** — All decisions are public.
- **Forkability** — Any group may fork and improve.

---

## Quick Reference

| Action | Process |
| :--- | :--- |
| Appoint Steward | Community vote, 2-year term, renewable |
| Remove Steward | 75% supermajority vote |
| Amend Treaty | Written proposal + 6-month comment + rough consensus |
| Resolve Dispute | Technical working group + community review |
| Ratify Treaty | Public declaration (PR to signatories/registry.md) |
