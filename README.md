# The Decentralized Commons Treaty

A non-commercial, community-governed social contract for the decentralized web. Protected against exploitation, open for participation.

Building the decentralized commons, together.

# Overview

This repository contains the Decentralized Commons Treaty — a social contract for an interoperable, resilient, and people-governed decentralized web.

The Treaty establishes:

Common principles for decentralized infrastructure

Technical standards (CIDs, naming, storage, identity)

Governance model (community-driven, interest-neutral Steward)

Dispute resolution (community-enforced, not legal)

Non-commercial protection (the text belongs to the commons)

Key Documents
```
File	Description
treaty.md	The full Treaty text
signatories/	Public registry of Signatories
governance/	Details on Steward selection, amendments, disputes
standards/	Technical specifications (CIDs, DHTs, storage)

```

# Principles

Interoperability First — No proprietary lock-in

Interest-Neutral Stewardship — Steward has no financial stake

People Govern — Rough consensus, no corporate veto

Transparency — All decisions are public

Forkability — Any group may fork and improve

Iterative Evolution — The Treaty is never finished

Preservation of History — Permanent, tamper-resistant knowledge
