# Contributing to the Decentralized Commons Treaty

Thank you for your interest in contributing. This is a community-driven effort, and every contribution matters—whether you're fixing a typo, proposing a new standard, or joining as a Signatory.

---

## How to Contribute

### 1. Read the Treaty
Start with [`treaty.md`](treaty.md) to understand the principles, commitments, and governance structure.

### 2. Choose Your Contribution Type

| Type | Description | How to Submit |
| :--- | :--- | :--- |
| **Editorial** | Typos, clarity, formatting | Pull Request |
| **Technical** | New standards, spec improvements | Pull Request + Issue |
| **Governance** | Amendments to the Treaty | Pull Request + Issue |
| **Ratification** | Joining as a Signatory | Pull Request (add your name) |
| **Discussion** | Questions, ideas, feedback | Issue or Discussion |

### 3. Submit a Pull Request

1. **Fork** this repository
2. **Create a branch** for your changes (`git checkout -b your-change`)
3. **Make your changes** with clear, descriptive commit messages
4. **Push** to your fork (`git push origin your-change`)
5. **Open a Pull Request** against the `main` branch

### 4. Engage in Discussion

- Be respectful and constructive.
- Explain the rationale behind your proposal.
- Be open to feedback and iteration.

---

## Types of Contributions

### Proposing an Amendment (Article III)

Amendments require:
1. A written proposal (in the PR)
2. A 6-month open comment period
3. Rough consensus of active participants

See [`governance/amendment-process.md`](governance/amendment-process.md) for full details.

### Adding a Standard (Article II)

New technical standards should be proposed as an RFC in the `rfcs/` directory. See [`rfcs/README.md`](rfcs/README.md) for the template.

### Becoming a Signatory

Add your name/project to [`signatories/registry.md`](signatories/registry.md) and submit a PR. No approval required—just show up.

This project is committed to providing a welcoming and harassment-free experience for everyone, regardless of background or identity.

**Be kind. Be constructive. Be patient.**
